---

## Projects

Here are the first four small projects I created to practice Python fundamentals:

### 1. Bill Splitter
* **What it does:** Calculates how much each person needs to pay when splitting a bill.
* **What I learned:** Basic math operations, user input handling, and float rounding.

### 2. Operator Practice
* **What it does:** A script specifically designed to practice decision-making in code.
* **What I learned:** Using `if`, `elif`, and `else` statements with comparison operators.

### 3. Cinema Ticket Calculator
* **What it does:** Determines the price of a movie ticket based on the user's age or student status.
* **What I learned:** Complex conditional logic and combining multiple criteria.

### 4. Employee Card Creator
* **What it does:** Generates a formatted text layout representing a company ID card.
* **What I learned:** String manipulation, variables, and formatting output in the console.

---

## How to Run These Projects

1. Make sure you have [Python](https://python.org) installed on your computer.
2. Clone this repository or download the files.
3. Open your terminal or command prompt.
4. Run any project by typing:
   ```bash
   python name_of_file.py
   ```
